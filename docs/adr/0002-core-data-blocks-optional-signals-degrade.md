# Core data blocks live use while optional signals degrade

The live draft is blocked when rankings, player identities, league settings, or confirmed keeper supply are stale or invalid because those failures can corrupt every recommendation. Experimental model output, contract context, and sportsbook signals instead degrade with explicit labels so optional evidence cannot make the Draft Workspace unavailable. This trades some analytical richness for dependable access under the draft clock while preserving truthful data provenance.
