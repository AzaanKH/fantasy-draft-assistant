Data and state rules

  • Keep fixed-width lanes for ranks, avatars, queue actions and metrics. Right-align numeric columns.
  • Apply one position color consistently across the board, roster and player metadata. Keep the position label visible.
  • Use cyan for actions, selection and focus. Yellow marks the active pick. Add explicit status text for the countdown.
  • While paused, freeze the timer and disable drafting. Queuing and player inspection stay available.
  • Pair injury, rookie, keeper and connection states with text. Color is a supporting cue.
  • Respect reduced motion. Avoid a continuously flashing clock. Announce pick changes without moving keyboard focus.
